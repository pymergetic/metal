Factory

The build card's live face: every discovered unit, its per-lane state from the event ring, and the in-kernel walk. Same faces on every seat — only the fill differs, so a seat without an ELF loader refuses the rebuild instead of hiding the pane.

Walk

Units compile one per coop quantum. The two jobs are separate: rebuild compiles for this seat's own arch and links the result into the running process, so it is offered for that arch alone; produce emits objects to download for any arch the seat can emit — including its own — and never touches what is running.
